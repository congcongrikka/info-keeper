# 信息管家 · Info Keeper

> 把零散的想法、资料和待办收进一处，再让初音陪你一起整理和回顾。

**线上地址：<https://your-deployment.example.com>**

---

## 一句话介绍

这是一个**邀请制的个人知识管家**。你只管把脑子里闪过的东西丢进去——一个想法、一条待办、一个链接、一段资料，剩下的分类、摘要、关联、回顾，都由它（和初音）帮你做完。

## 它帮你解决三件事

1. **记得住**：一个输入框，不分文件夹、不选标签，写完就走，不打断思路。
2. **理得清**：初音会自动起标题、判断类型、写摘要、打标签，还帮你找出「这条和之前哪条有关」。
3. **问得出来**：直接问它「上次那个方案我想到哪了」「这周有什么没做完」，回答只基于你自己写下的内容，还带出处。

## 初音特色 🎤

> 说明：下面描述的角色插画是**可选主题素材**，出于版权原因不随开源仓库分发；未安装时界面会显示中性占位，全部功能不受影响。详见 `public/miku/README.md` 与 `NOTICE`。

整套界面是「午夜深空 + 初音葱绿」的虚拟空间主题，初音不只是个图标，而是贯穿全程的陪伴者：

- **登录页**：初音站在舞台光里向你挥手，背后一圈葱绿光晕。
- **收件箱**：卡片右下角有 Q 版初音水印，轻轻渐隐，不打扰你。
- **问答**：左上角是初音头像，整幅缩放、带呼吸光环，像她正陪着你聊天。
- **空态页**：没有数据时，初音微笑着看向你，配一句「初音在等你的第一条总结 ♪」。
- **细节彩蛋**：八分音符 ♪、大葱元素散落在分割线和网格背景里，等你发现。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 快速记录 | 一个输入框收下想法 / 笔记 / 待办 / 链接 / 资料 |
| 自动理解 | 标题、类型、摘要、标签、重点、下一步、优先级、截止时间 |
| 自动关联 | 从旧记录里找出真正相关的那几条 |
| 智能问答 | 基于你的记录流式回答，句末标注出处可跳转 |
| 待办整理 | 自动排成「今天 / 本周 / 以后 / 卡住了」 |
| 阶段总结 | 按 7 / 30 / 90 天复盘，生成主题、进展和行动建议 |
| 多端同步 | 手机 / 平板 / 电脑共用同一份数据，联网即同步 |
| 数据导出 | 一键导出全部记录为 JSON，数据永远是你自己的 |

## 为什么是邀请制

为了保护共用的模型额度，注册需要邀请码。每个人只能看见自己写下的东西，数据通过数据库行级权限（RLS）严格隔离。**没有邀请码，谁也进不来。**
